# 📄 DocQuery

DocQuery is a beginner-friendly document question-answering application built with Python and Streamlit. It lets a user upload a PDF or TXT document, process its text, create embeddings, search for relevant content, and ask questions through a chat interface.

## Features

- Upload PDF and TXT documents
- Extract document text
- Split text into chunks
- Create text embeddings with Sentence Transformers
- Search using cosine similarity
- Ask questions through a Streamlit chat interface
- Display retrieved source text
- Basic conversation memory
- JSON-based caching and conversation storage

## Installation

Create and activate a Conda environment:

```bash
conda create -n docquery python=3.11
conda activate docquery
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Run the Application

From the directory containing `app.py`:

```bash
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal, normally:

```text
http://localhost:8501
```

## How It Works

```text
Upload Document
      ↓
Extract Text
      ↓
Create Chunks
      ↓
Generate Embeddings
      ↓
Store Vectors
      ↓
Ask Question
      ↓
Generate Question Embedding
      ↓
Cosine Similarity Search
      ↓
Retrieve Relevant Chunks
      ↓
Display Answer and Sources
```

## Current Scope

The current implementation uses retrieval and similarity search. The answer is based on the most relevant retrieved document chunk rather than being generated by an external large language model.
